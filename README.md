# SMSML – ASAH led by Dicoding

Repository ini berisi seluruh rangkaian proyek **MLOps** yang dilakukan dalam program **ASAH led by Dicoding**, mulai dari eksperimen dataset, preprocessing otomatis, pembangunan model machine learning/deep learning, workflow CI/CD, hingga sistem monitoring dan logging.

## Proyek ini mencakup:
- Eksperimen dataset dengan **EDA** dan preprocessing manual maupun otomatis.
- Pelatihan model dengan **MLflow Tracking UI**, hyperparameter tuning, dan evaluasi akurasi.
- Workflow **CI/CD** menggunakan GitHub Actions untuk retraining model secara otomatis.
- Sistem **monitoring** menggunakan Prometheus dan Grafana, serta penerapan alerting untuk memantau performa model.

Repository ini menunjukkan penerapan nyata pipeline **end-to-end MLOps** pada proyek NLP dan machine learning dengan fokus pada kualitas data, model, dan monitoring sistem.
